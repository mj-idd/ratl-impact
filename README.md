# لوحة أثر الحلقة القرآنية — جمعية رتّل بنجران

صفحة ثابتة تعرض نتائج **استبانة قياس الأثر القيمي للحلقة القرآنية** (١٨١ رداً)،
بمقارنة قيم الطلاب والطالبات قبل الالتحاق بالحلقة وبعده، مع مبدّل بين:
الكل / بنين / بنات، ومقارنة مباشرة بين الفئتين على المحاور الخمسة.

## الرابط
https://mj-idd.github.io/ratl-impact/

## التشغيل
الصفحة ملف واحد مكتفٍ بنفسه: `index.html` — يُفتح بأي متصفح، ولا يحتاج خادماً.

## تحديث البيانات
الأرقام مضمَّنة داخل `index.html` في متغيّر `D` أعلى وسم `<script>`.
